## ✨ Features

- Hero section with introduction and call-to-action buttons
- About Me section describing the developer profile and focus
- Services overview for website and web application work
- Project showcase with live demo and GitHub links
- Experience timeline for internship and professional background
- Resume section with downloadable PDF and resume viewer page
- Tech Stack section highlighting tools and technologies used
- Contact section with email, social links, and message form
- Responsive single-page design with mobile-friendly navigation

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/ShViNaY/Personal-Portfolio.git
```

2. Change into the project directory:

```bash
cd Personal-Portfolio
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the app in your browser:

```text
http://localhost:3000
```

## 🏗️ Production Build

```bash
npm run build
npm start
```

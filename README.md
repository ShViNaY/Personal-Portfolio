# Vinay S H — Personal Portfolio

A clean, responsive freelance portfolio built with Next.js, TypeScript and Tailwind CSS.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- React
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Before deploying

1. Replace `public/images/anime-developer.svg` with your preferred anime-style developer image.
2. Replace the two project placeholder SVGs with real project screenshots when you have them.
3. Add live-demo URLs in `components/Portfolio.tsx` by changing each project's `live` field.
4. Add more projects by adding another object to the `projects` array.
5. Deploy to Vercel.

## Contact

The contact form currently opens the user's email client using `mailto:`. No backend is required.
